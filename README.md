A single-file, dependency-free entry for the `news-image-20261121` bounty: a 1024x1024
newspaper-style news infographic for Saturday 21 November 2026 (the "front page").
Running the script copies the bundled `entry.png` into the output directory selected by
`MAKEFUN_OUTPUT_DIR` (default `/output`) and reports the copied byte size to stderr.

## Run it

```sh
node main.ts
```
